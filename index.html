APRENDE MIENTRAS EXPLORAS

¿Cómo funciona Fetch?

Cuatro pasos conectan una API pública con lo que ves en pantalla.

01
↗

Realizar la petición

fetch(url) inicia una solicitud HTTP y devuelve una promesa que se resolverá cuando haya una respuesta.

const response = await fetch(url);
02
✓

Verificar la respuesta

La propiedad response.ok permite comprobar si el estado HTTP indica éxito antes de procesar los datos.

if (!response.ok) throw Error();
03
{ }

Leer el JSON

response.json() también es asíncrono: transforma el cuerpo de la respuesta en datos utilizables por JavaScript.

const data = await response.json();
04
✧

Mostrar los datos

JavaScript utiliza los datos recibidos para crear tarjetas. try...catch ayuda a gestionar errores de red y del procesamiento.

renderCharacters(data);
✦

Recuerda: fetch() no rechaza automáticamente la promesa ante respuestas HTTP como 404 o 500. Debes verificar response.ok.
